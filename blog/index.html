Transformer

Posted on 2021-11-15 Edited on 2022-04-05

Framework

  • Encoder-Decoder based.
  • Use attention only which is different form seq2seq with attention.

PS: Embedding + Positional encoding.

Multi-head attention

For the same key, value, query, would like extract different information.

  • eg: short distance & long distance.

Multi-head attention uses \(h\) independent attention poolings.

  • Concat each independent attention poolings then get the final output.

Mathematical formula:

\(W_i^{(q)}\) corresponds FC Layer; \(f(...)\) means Attention Block; \(\begin{bmatrix}h_1\\\vdots\\ h_h\end{bmatrix}\) corresponds Concat Block.

Masked multi-head attention

When decode one output element, no need to consider the sequence after the current element.

Mask: When calculate the output of \(x_i\), pretend the length of sequence is \(i.\)

Positionwise FFN (Feed-forward Network)

\(1*1\) Convolution Layer ( Essentially FC Layer )

It is equivalent to \(FC\ Layer\) with the input shape of \(n_hn_w*c_i\) and weight of \(c_o*c_i\). \(n_h,n_w\) are the input image's shape.

There are 2 "FC Layer", which is same with \(1*1\) Convolution Layer. Positionwise FFN is FC Layer essentially.

  • Firstly \((bn, d)\) to \((b, n, d)\).
  • \(1st\ FC\ Layer:\) Input shape convert from \((bn, d)\) to \((bn, d')\).
  • \(2nd\ FC\ Layer:\) convert from \((bn, d')\) to \((bn, d)\).
  • Lastly \((b, n, d)\) to \((bn, d)\).

Layer Normalization

Subgraph on the left: It's residual structure. Block can be multi-head attention or positionwise FFN.

Batch Normalization work on each channel/feature.

  • Not suitable for NLP: because the length of sequence will change, the data distribution and experimental result are unstable.

Layer Normalization work on each sample.

  • Although the length will also change, experimental result is more stable.

Information transfer (form encoder to decoder)

\(y_1,\cdots,y_n\): are the output of enconder, which are as key&value in decoder ( red box ).

  • Query ( red box ) is from targets sequence.

PS: Other multi-head attentions are self-attention.

The above means that encoder have the same dimension and number of blocks as decoder.

  • Same number of blocks: means same depth.
  • Same dimension: ?

Prediction

When predict the \({t+1}_{th}\) output, decoder have the previous \(t\) predicted values.

  • The previous \(t\) predicted values as key & value.
  • \(t_{th}\) as key & value & query.

Summary

  • Transformer is an encoder-decoder with attention purely.
  • Encoder and decoder both have \(n\) transformer blocks.
  • Transformer block has multi-head attention, positionwise FFN and layer normlization.
